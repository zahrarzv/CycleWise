# The CycleWise Period Tracking System

## Project Overview
CycleWise is a menstrual health and cycle tracking Android appliction. This app is designed to provide users with private data-centric way to track, understand, and predict their menstrual health cycles.

## Build and Run
**1. Dependencies:**

- Android Studio - Current Stable Release
- JDK - Java 17
- Android SDK - API Level 34 (Android 14)
- Gradle - 8.8
- Mockito - 5.3
- Junit Jupiter - 5.10.2
- SQLite JDBC - 3.36.0.3
- AndroidXJunit - 1.2.1
- Espresso - 3.6.1

**2. Environment Configuration:**

Before building verify Gradle JDK
- Navigate to File > Settings
- Go to Build, Execution, Deployment > Build Tools >Gradle
- Set Gradle JDK to Java 17+

**3. Building:**

Running from Android Studio GUI, 
- Select Build > Make Project
- Wait for Gradle sync and build process to complete

**4. Running the application:**

This application is optimized for Pixel 9 device profile running Android 15(API 35) or Android 14 (API 34)
